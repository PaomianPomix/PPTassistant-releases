# 测试指南

自动化测试覆盖纯逻辑和文件处理；真实窗口、笔输入和 Office 交互需在对应桌面环境中检查。开发环境见 [开发指南](11-development.md)。

## 自动化测试

在仓库根目录执行：

```powershell
dotnet build .\src\PPTAssistant.sln -c Release
dotnet test .\src\PPTAssistant.Tests\PPTAssistant.Tests.csproj -c Release --no-build
```

测试工程使用 xUnit，覆盖坐标与 DPI、输入路由、墨迹几何、笔宽与色板、布局度量、InkML、OOXML 包写入、板书日志、擦除记录、写回编排、自启服务及更新检查。常规单元测试不需要启动 PowerPoint。

测试通过不代表全部设备兼容性已验证。真实压感笔、触摸抑制、混合 DPI、多屏定位、窗口层序和保存后墨迹的视觉效果需在对应环境中检查。

## 手工功能检查

使用已保存的课件测试副本；板书保存检查会修改指定文件。测试时记录应用版本、显示环境及输入设备，便于复现。

| 范围 | 检查内容 |
| --- | --- |
| 安装与启动 | 安装后可从开始菜单运行；托盘图标正确；重复启动只保留一份实例；可正常退出和卸载 |
| 宿主与放映 | 普通全屏放映显示工具栏，结束放映后收起；窗口和展台放映不显示；多屏时跟随放映屏幕 |
| 书写 | 鼠标、触摸和压感笔分别检查短点、长线、交叉和快速书写；切换笔宽/颜色只影响新笔画 |
| 擦除 | 扫过删除整笔；交叉处下层笔画完整；空白处不误删；长按清页；全部擦空后不写入课件 |
| 导航与浮窗 | 两侧翻页、缩略图跳页、色板、笔刷、放大镜可操作；不会夺走课件所需焦点 |
| 显示缩放 | 75%、100%、150%、200% 的工具窗可见且可点击；检查小屏、4K 和不同 Windows DPI |
| 保存与恢复 | 保留、丢弃、稍后处理分别符合预期；备份可打开；写回后墨迹页码、位置、颜色和粗细正确 |
| 设置 | 分类、搜索和颜色输入可用；修改自动保存；重启后设置显示正确；放映开始时设置窗口关闭 |
| 自启与更新 | 当前用户自启开启/关闭有效；实际重新登录后托盘驻留；手动检查更新正确处理版本和网络错误 |

保存检查应包含多页课件及中途失败情况，确认课件备份和残留板书可用于恢复。真实笔输入与模拟鼠标的结果应分别验证。自动保存模式的启动限制见 [配置参考](13-configuration.md)。

## 安装包检查

在完成构建与测试后，使用发布脚本生成安装包，步骤见 [开发指南](11-development.md)。检查安装包版本、应用图标、开始菜单入口、托盘运行和卸载入口，并在没有预装 .NET 的 Windows x64 环境中验证自包含运行。

可核对下载文件的 SHA256：

```powershell
Get-FileHash .\PPTAssistant-1.0.0-win-x64-Setup.exe -Algorithm SHA256
```

将输出与同一 Release 的 `SHA256SUMS.txt` 对照。发布标签、应用内版本和安装包文件名应使用同一版本号。

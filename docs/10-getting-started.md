# 使用指南

PPTAssistant 在 Windows 系统托盘中运行，在 PowerPoint 普通全屏放映时显示工具栏。下载入口为 [GitHub Releases](https://github.com/PaomianPomix/PPTassistant-releases/releases/latest)。

## 安装

- 操作系统：Windows 10/11 x64。
- 演示文稿应用：推荐桌面版 PowerPoint 2016 或更高版本。
- 课件：推荐已保存的 `.pptx` 文件。

下载 `PPTAssistant-<版本>-win-x64-Setup.exe`，按照安装向导完成安装，再从开始菜单启动。安装包自带 .NET 运行时，不需要安装开发工具或另外安装 .NET。升级前结束放映，处理板书，并从托盘退出正在运行的 PPTAssistant。

安装仅面向当前用户，默认目录为 `%LOCALAPPDATA%\Programs\PPTAssistant`，不需要管理员权限。可选择创建桌面快捷方式；卸载可从 Windows 的“已安装的应用”进入。卸载保留用户配置、板书记录与课件备份。

启动后通常没有主窗口；入口在任务栏通知区域，必要时展开隐藏图标。应用只运行一个实例，重复启动不会打开第二份窗口。

## 首次放映

1. 启动 PPTAssistant，并打开一份已保存的 `.pptx`。
2. 在 PowerPoint 中按 **F5** 开始普通全屏放映。屏幕底部出现中央工具栏和两侧翻页按钮。
3. 点击“笔”开始书写；用“色板”换颜色，用“笔刷”调整笔宽。
4. 按 **Esc** 或点击“退出放映”结束放映，再选择本次板书的处理方式。

窗口放映和展台模式不显示工具栏。双屏使用时，工具栏应出现在实际放映的屏幕上。WPS 及旧版 Office 的兼容性取决于宿主版本；正式使用前应检查书写、翻页和课件保存结果。

## 工具操作

| 工具 | 操作 |
| --- | --- |
| 指针 | 鼠标和手指可直接操作课件 |
| 笔 | 鼠标和手指在覆盖层书写 |
| 橡皮 | 点击进入擦除模式，扫过笔画即可删除整笔；长按约 0.8 秒清空当前页板书 |
| 色板 | 选择预设色、最近使用色，或通过取色器和 RGB 输入精调颜色 |
| 笔刷 | 调整 2–50 DIP 的基准笔宽 |
| 放大镜 | 拖动浮窗移动取景位置，用滚轮在 1–3 倍之间调节 |
| 两侧翻页按钮 | 上一页、下一页；点击页码展开缩略图，再点击缩略图跳页 |
| 退出放映 | 结束本次放映，应用继续驻留托盘 |

压感笔默认始终用于 PPTAssistant 书写，即使工具栏处于指针模式。需要用笔点击课件时，在设置的“画笔与书写”中关闭“压感笔始终用于书写”。系统不支持笔输入重定向时，应用会回落为由宿主接收笔输入。

点击预设或最近颜色后，色板会收起；拖动取色器和输入 RGB 时色板保持打开，完成后可自行关闭。

## 板书保存与恢复

默认在放映结束时询问是否保留板书：

- **是**：保存并暂时关闭课件，创建备份，把板书写入课件，然后重新打开。
- **否**：丢弃本次板书，不写入课件。
- **取消**：保留本机板书记录，稍后恢复。

如果本次板书已全部擦除，不会询问写回，也不会修改课件。写回失败时保留板书记录，可查看应用日志定位原因。

异常退出后，手动启动应用会检查残留板书。也可以在未放映时，从托盘选择“恢复上次板书…”。恢复按最新记录处理；如果提示课件被占用，先保存并关闭该课件，再恢复。残留板书记录保留 7 天，重要板书请及时处理。

设置的“板书保存”页还提供自动保留或自动丢弃。当前版本重启后，普通放映会话仍从“询问”开始；需要自动模式时，请在本次运行中先切换到其他模式，再选择所需模式。详见 [配置参考](13-configuration.md)。

## 设置与退出

右键托盘图标选择“设置…”。设置分为“放映与界面”“画笔与书写”“板书保存”“启动与更新”，支持搜索；可按 **Ctrl+K** 定位搜索框。

设置更改自动保存。放映界面可调到 75%–200%，下次放映生效；屏幕空间不足时会自动适配。放映中无法打开设置，开始放映时已打开的设置窗口会关闭。

“开机自启”默认关闭，仅影响当前 Windows 用户。开启后，登录时应用安静驻留托盘，残留板书可通过托盘菜单主动恢复。如果 Windows 已禁用该启动项，请在“设置 → 应用 → 启动”中启用。

“检查更新”按需访问 GitHub，发现新版本后提供发布页入口，由用户自行下载并安装。应用不会自动下载或安装更新。

结束使用时，从托盘菜单选择“退出 PPTAssistant”。仅结束放映不会退出应用。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动后没有窗口 | 检查托盘和隐藏图标；重复启动不会打开第二个实例 |
| 看不到工具栏 | 确认应用仍在托盘运行，并使用普通全屏放映；检查实际放映屏幕 |
| 工具栏太大或太小 | 结束放映，在设置中调整放映界面缩放，再重新放映 |
| 设置打不开 | 先结束当前放映 |
| 板书没有写入课件 | 查看日志；使用原位置的课件恢复；提示文件占用时先保存并关闭课件 |
| 开机自启不生效 | 确认设置开关与 Windows 启动应用列表均已启用；移动应用目录后重新开启自启 |
| 更新检查失败 | 检查 GitHub 网络访问，或直接访问项目发布页 |

托盘菜单可直接打开配置目录和日志目录。备份及板书记录路径见 [配置参考](13-configuration.md)。源码构建与开发环境见 [开发指南](11-development.md)。

# PPTAssistant 1.1.0

新增可独立使用的多页白板，适配不同分辨率与 Windows 缩放，并统一更新应用图标。

## 新增与改进

- **内置多页白板**：无需打开 PowerPoint，即可从托盘进入；放映中也可随时打开并返回课件。支持最多 100 页、黑白背景、笔色和笔宽、整笔擦除、逐页撤销重做与本机自动保存。白板内容不会写入课件。
- **底部触摸工具区**：所有白板操作移至底部，与设置页采用一致的 Notion 风格。返回入口固定在左下方，窄屏可横向滑动工具区，触摸目标至少 44 DIP。
- **自适应画布**：针对 4K、不同 Windows DPI、16:10、竖屏与小屏调整布局。已有笔迹等比例显示，换屏往返不累积缩放误差，新增空白区域也可书写。
- **清晰的 PNG 导出**：按当前屏幕像素密度导出当前页完整可写区域，包含背景、不含工具栏。使用“导出 PNG”或 Ctrl+S；多页内容可分别导出。
- **新版统一图标**：应用、窗口、托盘、安装程序和开始菜单/桌面快捷方式使用同一套新图标。
- **保存与返回**：返回或正常退出前先完成当前笔画再保存；保留旧版白板文件读取能力，并改进白板与放映之间的工具恢复和焦点处理。

## 安装与升级

下载并运行 `PPTAssistant-1.1.0-win-x64-Setup.exe`。需要 Windows 10/11 x64；PowerPoint 放映功能推荐桌面版 PowerPoint 2016 或更高版本和已保存的 `.pptx` 文件。安装包自带 .NET 运行时，无需另外安装。

升级前结束放映、处理板书，再从托盘退出 PPTAssistant。升级和卸载保留当前用户的配置、白板文档、板书记录与课件备份。旧白板文件会在下次成功保存时迁移为支持逐页尺寸的 v2 格式；若计划回退旧版应用，请先复制原白板文件备份。

安装包未进行代码签名；可用同一发布页的 `SHA256SUMS.txt` 核对下载文件。

## 验证范围与已知限制

已验证白板笔迹与压力保存、分页和撤销、旧文件迁移、保存失败保护、窗口生命周期、底部控件操作，以及不同分辨率下的布局和 PNG 像素尺寸。4K 的 100%/150%/200% DPI 通过真实 WPF 控件的离屏布局模拟验证；真实触摸大屏、压感笔和混合 DPI 多屏放映仍需在授课设备上检查。WPS 及旧版 Office 的兼容性同样取决于具体环境。

普通放映会话在应用重启后仍从“每次询问”保存板书开始；如需自动保留或自动丢弃，请在本次运行中先切换到另一项，再选回所需模式。此限制不影响白板自动保存。

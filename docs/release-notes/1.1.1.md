# PPTAssistant 1.1.1

修复放映书写时，压感笔墨迹在起笔、收笔处偶尔出现异常圆点或鼓包的问题。

## 修复

- 正确处理压感笔起笔、抬笔时的零压力，避免端点突然变粗。鼠标和触摸书写继续保持等宽。
- 新增零压力端点与无压感设备的回归测试；本次问题已通过实际放映书写验收。

## 安装与升级

下载并运行 `PPTAssistant-1.1.1-win-x64-Setup.exe`。支持 Windows 10/11 x64，安装包自带 .NET 运行时。升级前请结束放映、处理板书并从托盘退出应用。

安装包未进行代码签名，可使用同页的 `SHA256SUMS.txt` 核对下载文件。

本版本为 1.1.0 的墨迹修复版本，其他功能与兼容性范围保持不变。

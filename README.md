# PPTAssistant

PPTAssistant 的公开版本发布渠道，用于 Windows 上的 PowerPoint 放映辅助工具。

[查看正式版本与下载](https://github.com/PaomianPomix/PPTassistant-releases/releases)

应用内可通过系统托盘 → 设置 → 启动与更新 → 检查更新查询最新正式版本。发现新版本时仅提供本仓库的发布页链接，由用户自行下载；不会自动下载或安装。

每个版本的运行环境、下载文件和变更说明以对应 Release 为准。若发布列表为空，表示尚未发布正式版本。

本仓库仅用于版本发布，不包含源码或逆向资料。
